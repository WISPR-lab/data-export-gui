## Note on Screening Flowcharts

We produced these screening flowcharts to help guide our operational protocol when consultants are trying to decide whether it would benefit a client to request and analyze their data exports. 

Here, we try to provide guidance for two major questions:

- *Relevance:* Data exports offer more information than account security interfaces, but more information is not always strictly _better._  This chart attempts to help consultants decide whether the extra data/capabilities provided by data exports can meaningfully serve clients' goals. 
- *Safety:* This flowchart aims to help consultants ensure that the client can safely request and store data exports.
